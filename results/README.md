Regeneration order (each step needs the previous one's outputs):

```bash
python scripts/clinical_reference.py            --out results/
python scripts/ecgcipa_reference.py             --out results/
python scripts/build_wells.py --workbook Blinova_etal_2018_data.xlsx
python scripts/invitro_and_bridge.py --wells data/cipa_myocyte_wells.csv --out results/
python scripts/validate_invitro_correction.py   --out results/
python scripts/arm_confounding.py --wells data/cipa_myocyte_wells.csv --out results/
python scripts/waveform_analysis.py --out results/ --wf <waveform dir> --index <index csv>
python scripts/ord_simulation.py 24             # needs myokit + SUNDIALS
python scripts/qnet_simulation.py 24
python scripts/qnet_28drugs.py 24
python scripts/delineation_shift.py --wf <median-beat dir> --out results/
python scripts/risk_comparison.py --wells data/cipa_myocyte_wells.csv --out results/
```

`data/cipa_myocyte_wells.csv` is built from the Blinova 2018 workbook, which this
repository does not redistribute - download it from the CiPA Data Resources page
first. The simulation scripts need a working myokit build (SUNDIALS headers and a
C compiler); see `docs/RISK_CLASSIFICATION_28.md` for the parameter sources.
